# Contributing guide

Thank you for your interest in contributing to this project. Before you start, please open an issue describing the change you would like to make so we can discuss the approach.

Keep your commits small and focused, and write clear commit messages so reviewers can follow your changes. All contributions go through pull requests, and they are merged only after the review requirements are met.

If you are unsure about anything, ask a question on the relevant issue — no question is too small.
